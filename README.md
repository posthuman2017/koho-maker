# 施設だより作成ツール

介護・障害・保育などの事業所で発行している「○○だより」「○○通信」といった広報誌を、
ブラウザだけで作成し、A4で印刷（PDF保存）するためのツールです。

**インストール不要／写真も文章も外部に送信しません。**

👉 **[ツールを開く](https://posthuman2017.github.io/koho-maker/)**

---

## これまでExcelで作っていた方へ

Excelでの広報誌づくりは、行の高さやテキストボックスの位置合わせに時間がかかりがちです。
このツールは紙面を「部品（ブロック）」の積み重ねとして扱うので、

- 文字は紙面をクリックしてそのまま書き換え
- 写真は点線の枠をクリック、またはドラッグ＆ドロップ
- 部品の右上のボタンで並べ替え・複製・削除
- 「次の号を作る」で、前号のレイアウトをそのまま引き継いで新しい号を開始

という流れで作れます。行や列がずれる心配はありません。

## 使える部品

| 部品 | 用途 |
| --- | --- |
| 見出し帯 | 記事の見出し（色は6色から選択） |
| 本文 | 記事の本文（枠のデザイン・文字サイズを選択、**縦書きに切替可**） |
| 写真 | 1〜4列のグリッド。**形（四角／角丸／円／楕円／対角を丸く）**、比率、フチの色、傾き、説明文、背景（空と草原／季節色）を選択 |
| イラスト | **透過PNGのイラストを並べる専用の部品**（大きさ・位置・左右反転） |
| お誕生日 | HAPPY BIRTHDAY の飾りとお名前 |
| 寄稿・作文 | ご利用者様の作文などの掲載欄（**縦書きに切替可**） |

紙面のヘッダー（だよりの名前・発行日・号数）は自動で入ります。

## 縦書きについて

年頭のご挨拶やお品書きなど、縦書きにしたい記事は「本文」「寄稿・作文」の設定（⚙）から切り替えられます。

- 縦書きは**高さを決める必要があります**（45mm〜ページいっぱい230mmから選択）
- 文字が入りきらないと赤い点線と注意書きが出ます。高さを増やすか、文章を短くしてください
- **半角の数字（123）は横に倒れます。全角（１２３）で入力してください**

## イラストについて

「イラスト」の部品は、写真と違って白いフチや影がつかず、**背景の透過をそのまま残します**
（写真はJPEGに変換して軽くしますが、イラストはPNGのまま取り込みます）。

**イラスト素材はこのツールには含まれていません。** ふだんお使いの素材サイトからダウンロードしたものをご利用ください。
配布されている素材には利用できる範囲が定められているものがありますので、各サイトの利用条件をご確認ください。

## 保存について

- 編集内容は**そのパソコンのブラウザの中**（IndexedDB）に自動保存されます
- 過去の号は「保存した号を開く」から呼び出せます
- 別のパソコンへ渡すときやバックアップには「ファイルに書き出す（.json）」を使います

## 印刷のコツ

印刷画面で **「背景のグラフィック」にチェック**を入れてください。色や枠がそのまま印刷されます。
PDFで残したいときは、プリンターの選択で「PDFとして保存」を選んでください。

## 写真について

- 取り込み時に自動で長辺1600pxまで縮小するので、ファイルが重くなりすぎません
- iPhoneのHEIC形式は読み込めません。JPEG（.jpg）で保存してからお使いください
- 顔の位置がずれるときは、写真左上の「位置」ボタンで上下の位置を調整できます

## ご利用にあたって

ご利用者様やご家族が写った写真を扱います。掲載してよいかの確認は、これまでどおり施設の手順に沿って行ってください。
本ツールは写真を外部へ送信しませんが、編集中のデータはパソコンの中に保存されます。共有パソコンでお使いの場合はご注意ください。

## 動作環境

Windows / Mac の Google Chrome、Microsoft Edge（最新版）。
`index.html` 1ファイルだけで動くので、ダウンロードしてローカルで開いても使えます。
